# Paula's Desktop — UGC Creator

A complete static website for GitHub + Vercel, using a cream, blush pink, and brown visual style.

## Important: upload the file structure exactly as shown

```text
paulas-desktop-ugc-complete/
├── index.html
├── styles.css
├── script.js
├── README.md
└── assets/
    └── paula-portrait.jpg
```

Do not upload only `index.html`. Upload all files and the entire `assets` folder to the **same repository root**.

## Deploy
1. Download and extract this ZIP.
2. Create a GitHub repository.
3. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder directly to the repository root. Do not put the whole extracted parent folder inside another folder.
4. In Vercel, select **Add New → Project**, import that repository, and deploy it as a static site.
5. No framework preset or build command is needed. If asked, use “Other” and leave build command blank.
6. After uploading changes, redeploy from Vercel or push a commit to GitHub if connected.
